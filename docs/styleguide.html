PawPlate style guide

One shared background, glass on top, and colour only where it means something. Every piece below is drawn with the app's real CSS, so this page changes whenever the app does.

Colour rule

Fills are glass or white. Colour marks only (1) the active item, as a tinted glass pill; (2) the main action, in pink; (3) a state or a data value, such as saved, overdue, modality counts or highlights. Everywhere else, colour lives in the text or in a small icon or dot.
